# Hamqadam web-design and localhost fix

This build replaces the previous screenshot-based homepage shortcut with live, responsive Blade/HTML/CSS.

## WebDesign.zip implementation

The supplied visual references are implemented as live Laravel views for:
- Home
- Active Members Discovery
- Premium Plans
- Happy Stories
- Help & Support

The design PNGs are not embedded as page backgrounds or page replacements. Existing Laravel forms, routes, package actions, member interactions, ticket submission, profile links and dynamic data remain functional.

## Local/subdirectory URL fixes

The application now derives its mount path from the current request and physical document root, so assets and generated URLs stay within `/hamqadam` when the project is installed under XAMPP `htdocs/hamqadam`.

Supported deployment shapes include:
- `https://localhost/hamqadam/` with repository root under `htdocs/hamqadam`
- rewrite through `https://localhost/hamqadam/public/...`
- Apache/Nginx virtual host pointed directly at Laravel `public/`
- normal domain-root deployment

Missing local uploaded images fall back to the existing placeholder image instead of emitting known-broken image URLs.

## JavaScript/Firebase fixes

- Firebase Messaging only initializes when every required web configuration value is present.
- The service worker is available for both repository-root and `public/`-root hosting layouts.
- Guest pages no longer render member-only call JavaScript with empty authenticated user IDs.
- Dynamic JavaScript values that can contain quotes are emitted with JSON-safe Blade output.

## Deployment

Preserve your production `.env` and `public/uploads` contents when replacing an existing installation. The source archive supplied for this task did not include Composer's `vendor/` directory, so preserve the server's existing `vendor/` folder or run `composer install` using the included `composer.lock`.

After replacement:

```bash
php artisan optimize:clear
php artisan migrate --force
```

On Apache/XAMPP, `mod_rewrite` and `AllowOverride All` must be enabled for the project directory.
